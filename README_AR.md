## التشغيل من المصدر على Windows

1. ثبّت Python 3.11 أو 3.12 نسخة 64-bit من python.org.
2. افتح Command Prompt داخل مجلد المشروع وشغّل:

```bat
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python run.py
```

أو شغّل `run_windows.bat` لإنشاء البيئة وتثبيت المتطلبات تلقائياً. عند أول تشغيل يظهر معالج إنشاء المدير وبيانات الجمعية والتعرفة والأرصدة. أضف القراءات الافتتاحية مع الأعضاء.

## إنشاء ملف EXE ومثبّت Windows

على **حاسوب Windows 10/11 x64**، ثبّت Python 3.11/3.12 وInno Setup 6، ثم:

```bat
build_installer.bat
```

السكربت ينفذ الاختبارات أولاً، ثم PyInstaller، ثم Inno Setup. النتائج:

- البرنامج: `dist\MustacomAquaGestionPro\MustacomAquaGestionPro.exe`
- المثبّت: `dist_installer\MustacomAquaGestionPro_Setup_1.0.0.exe`

ينشئ المثبّت اختصار سطح المكتب وقائمة ابدأ ومدخلاً لإلغاء التثبيت. إلغاء التثبيت **لا يحذف قاعدة البيانات** حمايةً للسجلات.

> بيئة الإنجاز الحالية Linux؛ لذلك لا يدّعي هذا التسليم أن ملف EXE/المثبّت الثنائي قد بُني أو اختُبر على Windows. ملفات البناء والمثبّت الفعلية مضمنة، ويجب تشغيلها على Windows واختبار التثبيت والطابعة قبل التسليم الإنتاجي للجمعية.

اتبع **[دليل GitHub Actions والتنزيل](GITHUB_ACTIONS.md)**. إضافة الـ workflow لا تعني أن المثبّت أُنشئ؛ لا يظهر رابط التنزيل الفعلي إلا بعد نجاح التشغيل على GitHub.

## مكان قاعدة البيانات

```text
%LOCALAPPDATA%\MUSTACOM\MustacomAquaGestionPro\mustacom_aqua.db
```

توجد بجانبها مجلدات `attachments` و`backups` و`exports` و`logs`. يمكن فتح المكان من التطبيق. لا تضع قاعدة الإنتاج داخل مجلد التثبيت. قاعدة البيانات خاصة بحساب مستخدم Windows الحالي؛ استخدم حساب Windows نفسه، أو انقل نسخة احتياطية عند تغيير الحساب.

## النسخ الاحتياطي والنقل

1. افتح «النسخ الاحتياطي» واختر مجلداً آمناً واضغط «إنشاء نسخة الآن».
2. استخدم كلمة مرور للنسخة المشفرة إن رغبت؛ فقدانها يمنع فك التشفير.
3. للنقل، انسخ ملف `.mustabak` أو `.zip` إلى الحاسوب الجديد ثم استخدم «استعادة نسخة». تنشأ نسخة أمان تلقائياً قبل الاستبدال.
4. النسخة المحمولة `.db` تنقل قاعدة البيانات وحدها؛ النسخة الاحتياطية الكاملة تنقل المرفقات أيضاً.
5. النسخ المجدول يعمل **فقط أثناء تشغيل التطبيق**. الاحتفاظ `0` يعني عدم حذف النسخ القديمة.

لا توجد مزامنة متعددة الحواسيب. العمل المتزامن على أكثر من جهاز يحتاج بنية خادم إضافية غير مضمنة.
